# Front exterior — current package v3

The exterior follows backgrounds 001, 044 and 047. Lawn elevation is -1.2 m; eight steps reach the porch at hall level. Roof and tower proportions are provisional. Both stair-side bushes and the recessed metal grating behind the left bush are present. The named `under_porch_grating` port stays closed with no destination. The hall owns the front double doors.

## Files and rebuild

- `build.py` and `room.json`: current geometry recipe, ports, navigation dimensions and bake settings.
- `generated/blender/front_exterior/front_exterior_source_v3.blend`: editable source scene.
- `generated/blender/front_exterior/front_exterior_v3.blend`: baked Blender scene, including shared doors for previews.
- `generated/models/rooms/front_exterior_v3.glb`: room export; its compact GLB and gzip sidecar are generated by sync.
- `generated/previews/rooms/front_exterior/`: current room views; `generated/reports/rooms/front_exterior/shading_report_v3.json` records the bake.

```bash
python3 scripts/build.py room front_exterior
python3 scripts/build.py check
./walkthrough.sh build
```

The original EGA colors and soft baked vertex lighting work without browser GI. Standard doors use the [shared kit](../../shared/doors/README.md). Interactive doors start closed; E, click or touch opens them. Room placement and connections live in `house/layout.json`.

Superseded design iterations were removed. Keep the active files named in `room.json`; see [architecture](../../docs/architecture.md) for the workflow.

The independent exterior space owns the complete upper facade, siding, windows and continuous porch canopy. It does not rely on the plant room to fill a wall opening. Upstairs rooms occupy separate runtime spaces, so their floors do not require cuts or lowered columns in the exterior.

## Source and generated files

This folder contains only the builder, authored `room.json` and documentation. Original artwork is in `source/`. Generated scenes live in `generated/blender/front_exterior/`; GLBs in `generated/models/rooms/`; previews in `generated/previews/rooms/front_exterior/`; derived door metadata and shading reports in `generated/reports/rooms/front_exterior/`. Builders never write derived data back into `room.json`.
