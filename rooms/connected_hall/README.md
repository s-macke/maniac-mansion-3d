# Entrance hall and landing — current package v6

The entrance (010), staircase and upper landing (011) form one continuous unit. The builder generates entrance geometry in memory through the local `entrance.py` module, then adds the landing and current doors. No intermediate Blender scene is needed. The hall owns the interactive front double doors and the leaves connecting to the living room and kitchen. The rear kitchen entry fits below the gallery. The hall also owns the landing doors to the plant room, music room and security corridor. The reinforced door has separate shared leaf/frame meshes and opens from both sides.

## Files and rebuild

- `entrance.py`: entrance geometry generator used by the combined hall builder.
- `build.py` and `room.json`: current geometry recipe, ports, navigation dimensions and bake settings.
- `generated/blender/connected_hall/connected_hall_source_v6.blend`: editable source scene.
- `generated/blender/connected_hall/connected_hall_v6.blend`: baked Blender scene, including shared doors for previews.
- `generated/models/rooms/connected_hall_v6.glb`: room export; its compact GLB and gzip sidecar are generated by sync.
- `generated/previews/rooms/connected_hall/`: current room views; `generated/reports/rooms/connected_hall/shading_report_v6.json` records the bake.

```bash
python3 scripts/build.py room connected_hall
python3 scripts/build.py check
./walkthrough.sh build
```

The original EGA colors and soft baked vertex lighting work without browser GI. Standard doors use the [shared kit](../../shared/doors/README.md). Interactive doors start closed; E, click or touch opens them. Room placement and connections live in `house/layout.json`.

Superseded design iterations were removed. Keep the active files named in `room.json`; see [architecture](../../docs/architecture.md) for the workflow.

## Source and generated files

This folder contains only the builder, authored `room.json` and documentation. Original artwork is in `source/`. Generated scenes live in `generated/blender/connected_hall/`; GLBs in `generated/models/rooms/`; previews in `generated/previews/rooms/connected_hall/`; derived door metadata and shading reports in `generated/reports/rooms/connected_hall/`. Builders never write derived data back into `room.json`.
